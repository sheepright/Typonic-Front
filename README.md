## ⚓ 프로젝트 소개

- `소개` : TYPONIC 서비스는 개발자 친화적인 코드 연습 및 단어 연습을 제공하며 사용자 맞춤 연습 서비스도 제공하고 있습니다.
- `개발자` : FE: 전주현, 양민재 BE: 안양우, 김건우
- `더 나은 서비스` : 서비스 개선과 요청사항이 있으시면 typonic.typingTest@gmail.com 이메일로 연락주시면 감사하겠습니다.
- `GitHub` : 해당 서비스는 GitHub에 Open Source로 올려져있습니다.
- `Motif And Theme` : 'MonkeyType' 서비스에서 영감 및 테마를 받아서 제작하였습니다.

## 🚢 다양한 컨텐츠의 타자연습 사이트

- `C+, C#, Java, Python, JavaScript 등`의 다양한 언어의 코드 연습 및 단어 연습 제공.
- `원하는 카테고리 입력` 자신이 원하는 커스텀 타자 연습도 제공.
- `문장 붙여넣기, 파일 첨부 등` 다른 문서를 참고해서 연습하는 서비스도 제공.

## 🐋 깔끔하고 안정적인 UI/UX 구현

- `코드 에디터와 같은 UI 구현` 으로 코드 연습 등을 진행할 때 좀 더 몰입감을 제공.
- `각진 X, 둥근 O` 둥글둥글한 디자인으로 사용자에겐 편안함 제공.
- `어두운 색상의 배경` 을 통하여 사용자가 시각적으로 피로도를 감소.
- `다양한 폰트들` 을 사용하여 사용자에게 다양한 경험을 제공.

## 📘 서비스이용 가이드

- `안내사항` : AI를 통해서 문장을 생성하고 표시하여 로딩시간이 지연될 수 있습니다. 선택 후 잠시만 기다려주세요.
- `시작하기` : 타자연습의 시작은 타이핑을 입력하는 시점부터 시작됩니다.
- `주의사항` : 줄 바꿈은 엔터를 통해서 비어있는 칸만큼 줄바꿈을 진행해주시고 코드 앞 빈 공간은 TAB을 통해서 진행해주시면 됩니다.
- `랭킹등록` : 이름과 이메일 통해서 등록되며 자신의 이메일을 사용하여 등록하여 주세요. (이메일은 랭킹 저장시에 중복체크에만 사용됩니다.)
- `랭킹보기` : 타수를 기준으로 랭킹이 매겨지며 동일한 타수일 경우 정확도를 통해서 나눠집니다.
